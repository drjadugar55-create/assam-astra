# ASSAM ASTRA Phase 2

Bilingual (English/Assamese) Next.js frontend for ADRE Grade III preparation.

## Pages
- `/` Homepage
- `/adre-grade-iii` Exam hub and preparation areas
- `/mock-tests` Interactive five-question demonstration quiz
- `/pyqs` Sample question library with subject filter and explanations
- `/current-affairs` Current-affairs content hub
- `/dashboard` Student dashboard preview
- `/login` Login UI placeholder

## Run in GitHub Codespaces
```bash
npm install
npm run dev
```
Open port 3000.

## Production build
```bash
npm run build
```

## Important
This is a frontend prototype only. Authentication, database, verified PYQs, live news, admin panel, real server-side test evaluation, payments and subscription enforcement are not connected. Demonstration questions are not official ADRE papers. Verify exam details against the latest official recruitment notification. Do not collect real credentials in this version.
